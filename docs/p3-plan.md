# 3단계(P3) 기획안 — 알림과 설정

작성: 총괄 PM, 2026-11-18. 이 문서는 "무엇을, 왜" 만드는지 정한다. 역할 간 API·화면 약속은 `docs/p3-contract.md`에 있다.

## 1. 배경
- 2단계까지 메시지 기능(읽음 확인, 검색, 답장, 반응, 공지, 관리자 화면 등)은 갖췄지만, **알림**과 **개인 설정**은 기능별로 흩어져 있다.
  - 알림 끄기는 대화방 메뉴에, 방해 금지는 상태 창에, 시작 시 실행은 트레이 메뉴에 있다.
  - 알림은 "Windows 팝업 한 종류"뿐이라 미리 보기 숨기기, 소리, 키워드 같은 조절 수단이 없다.
- 기존 메신저(카카오톡, 슬랙, 팀즈, 라인웍스, 공공기관 업무 메신저)는 알림·설정을 한 화면에 모으고, 업무용은 "중요 메시지"와 "공지 확인 요청"으로 놓치면 안 되는 메시지를 따로 다룬다.

## 2. 목표
1. **한 곳에서 설정한다**: 설정 화면 하나에 내 정보, 알림, 화면, 대화, 보안·개인정보, PC 앱을 모은다.
2. **알림을 내가 조절한다**: 미리 보기, 소리, 잠시 끄기, 키워드, 작업표시줄 표시.
3. **놓친 것을 한 번에 본다**: 알림 센터(멘션, 내 글 답장, 내 글 반응, 공지, 키워드).
4. **놓치면 안 되는 것은 반드시 닿는다**: 중요 메시지, 공지 확인 요청.
5. **기관 정책은 관리자가 정한다**: 미리 보기 숨김 강제, 업로드 확장자 차단.

## 4. 화면 구성
- **설정 화면**: 왼쪽 레일 아래 톱니 아이콘 → 큰 창(모달).
  - 탭: 내 정보 · 알림 · 화면 · 대화 · 보안·개인정보 · PC 앱(데스크톱 앱에서만)
  - 바꾸면 바로 저장한다. "저장" 버튼은 없다. 비밀번호와 키워드처럼 입력이 필요한 것만 버튼이 있다.
  - 관리자가 강제한 항목은 잠금 표시와 "기관 정책으로 고정됨" 문구를 보여 준다.
- **알림 센터**: 레일의 종 아이콘(안 읽은 개수 배지) → 오른쪽 서랍.
  - 탭: 전체 · 멘션 · 답장·반응 · 공지
  - 항목을 누르면 그 메시지로 이동한다. "모두 읽음"을 누르면 배지가 지워진다.
- **잠시 알림 끄기**: 종 아이콘을 길게 누르거나 우클릭, 또는 설정 > 알림. 끈 동안 종에 "꺼짐" 표시와 남은 시간을 보여 준다.
- **중요 메시지**: 보내기 버튼 옆 메뉴 "중요 메시지로 보내기". 말풍선에 붉은 띠와 "중요" 표시가 붙고, 받는 사람에게는 소리와 함께 사라지지 않는 알림이 간다.
- **공지 확인 요청**: 공지로 등록할 때 "확인 요청" 체크.
  - 받는 사람: 공지 바에 "확인" 버튼이 나온다.
  - 등록한 사람: "확인 N/M명"을 누르면 확인한 사람과 안 한 사람이 보인다.
- **관리자 화면**: "정책" 탭을 추가한다(미리 보기 숨김 강제, 업로드 확장자 차단, 현재 업로드 최대 크기 표시).

## 5. PM 기본값(사용자 확인 전 잠정)
- 미리 보기 기본값은 **전체**, 알림음 기본값은 **켬(기본 소리)**, 작업표시줄 깜박임은 **켬**.
- 중요 메시지는 **누구나** 보낼 수 있다. 전체 대화방에서는 **관리자만** 쓸 수 있다. 한 사람이 **시간당 10번**까지만 보낼 수 있다.
  - 받는 쪽의 방해 금지·알림 끄기·잠시 끄기를 무시한다.
  - 관리자 정책 "미리 보기 숨김"은 무시하지 않는다.
- 공지 확인 요청은 공지를 올릴 수 있는 사람이면 누구나 건다. 확인 기록은 공지가 해제돼도 감사 로그에 남는다.
- 알림 센터는 최근 **30일**, 종류마다 최대 **200개**까지 보여 준다.
- 개인 자동 잠금은 "관리자 값 이하"에서만 고른다(0=끔은 관리자 값이 0일 때만).
- 창 닫기 기본값은 지금처럼 **트레이로 숨기기**. 전역 단축키 기본값은 **꺼짐**.

## 6. 진행 순서
| 묶음 | 내용 | 주 담당 |
|---|---|---|
| 3-A | 설정 화면 틀 + 알림 세부(미리 보기, 소리, 잠시 끄기, 키워드, 작업표시줄) + 기존 설정 이동 | 프론트, 백엔드, 데스크톱 |
| 3-B | 알림 센터, 중요 메시지, 공지 확인 요청 | 백엔드, 프론트 |
| 3-C | 개인 설정(내 정보, 화면, 대화, 보안·개인정보, PC 앱) | 프론트, 백엔드, 데스크톱 |
| 3-D | 관리자 정책 탭 | 백엔드, 프론트 |

- 디자이너는 v4 시안(설정 화면, 알림 센터, 중요 메시지, 공지 확인, 어두운 테마)을 먼저 낸다.
- 프론트는 목업과 시안이 나오는 대로 묶음 순서로 붙인다.
- 묶음마다 QA → 리뷰 → PM 커밋(커밋은 사용자 지시가 있을 때).

## 7. 위험과 대응
- **어두운 테마**: 지금 CSS가 색을 직접 쓰는 곳이 많으면 작업이 커진다. 프론트가 먼저 색을 변수로 모으고, 3-C 안에서 진행한다.
- **프로필 사진**: Zulip의 공개 API에 사진 업로드가 없을 수 있다. 백엔드가 조사해 보고하고, 안 되면 관리자 화면에서 등록하는 방식으로 바꾼다.
- **전역 단축키**: Tauri 플러그인을 새로 넣어야 한다(의존성 추가). 다른 프로그램과 겹칠 수 있어 기본값은 끈다.
- **중요 메시지 남용**: 횟수 제한을 두고 감사 로그에 남긴다.
- **PC 부하**: 동시에 일하는 세션은 백엔드·프론트·데스크톱·디자이너 4개로 유지하고, 설치 파일은 로컬에서 빌드하지 않는다(CI 사용).
