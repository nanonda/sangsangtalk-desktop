# 거돌이 이미지 제작 의뢰서

상상톡(음성군 직원용 업무 메신저)에서 쓸 마스코트 **거돌이** 그림을 의뢰합니다.
근무 상태 그림 7종(1차)과 대화용 이모티콘 8종(2차)입니다. 기준: 상상톡 기획안 v1 6절.

## 1. 쓰임
| 구분 | 어디에 보이나 | 화면 크기 |
|---|---|---|
| 근무 상태 | 직원 목록·대화 목록의 아바타 배지, 대화창 머리글, 내 프로필 메뉴, 트레이 메뉴 | 20px · 32px |
| 대화 이모티콘 | 메시지 반응(말풍선 아래 작은 칩), 입력창 이모티콘 고르기 | 32px |
| 보낸 이모티콘 | 대화창에 크게 보내는 그림 | 96px |

배경은 흰색·연회색(`#f1f6f7`)과 **레일 남색(`#0b4a8f`~`#062c58`)** 두 종류입니다. 두 배경 모두에서 잘 보여야 합니다.

## 4. 파일 규격
- 원본 **512 × 512px PNG**, sRGB, **실제 투명 배경(알파 채널)**.
  - 흰 배경을 지운 이미지는 안 됩니다. 지금 앱의 마스코트는 흰 배경을 지우면서 눈 흰자까지 투명해져 어두운 배경에 쓸 수 없습니다. **눈 흰자·이 등 흰 부분은 불투명한 흰색**으로 칠해 주세요.
- 파일명: `gedol-<영문이름>.png`, 소문자와 하이픈만(위 표 그대로).
- 캐릭터는 정사각형 안에 꽉 차게, 사방 여백 약 6%(32px). 그림자(바닥 타원)는 넣지 않습니다.
- **얼굴 위치를 모든 그림에서 같게** 해 주세요(머리 중심이 대략 위에서 38% 지점). 작은 크기로 바뀌어도 깜빡이지 않게 보입니다.
- 가능하면 원본 벡터(AI 또는 SVG)도 함께 주세요.

## 5. 작은 크기에서 알아보기
- 20px에서도 상태를 알아볼 수 있게 **포즈는 단순하게, 소품은 크게** 그립니다(수첩·숟가락·가방·모자).
- 가는 선과 작은 무늬(등껍질 무늬 등)는 작은 크기에서 뭉개지므로 줄여 주세요. 필요하면 **20·32px 전용 단순판**을 따로 주세요(`gedol-meeting@small.png`).
- 외곽선은 지금 캐릭터처럼 진한 보라(`#3b2a78` 계열)로 유지합니다. 남색 배경 위에서 윤곽이 사라지지 않게 **외곽선 바깥에 1~2px 흰 테두리**를 두르는 것을 권합니다.
- 기존 거돌이 색(연두 몸, 파란 모자, 노란 배)을 유지합니다.

## 6. 납품물
1. 근무 상태 7종 PNG(512px) — 1차
2. 대화 이모티콘 8종 PNG(512px) — 2차
3. 원본 벡터 파일
4. **미리보기 시트 한 장**: 모든 그림 × 3개 크기(20·32·96px)를 흰 배경과 남색 `#0b4a8f` 배경에 각각 나열한 PNG 또는 PDF

## 7. 보내는 방법
GitHub 저장소에 브랜치를 만들어 `design/assets/gedol/` 아래에 올리고 PR을 열어 주세요.
상상톡 디자인 담당이 접수해 화면에 맞춰 보고 의견을 드립니다.
