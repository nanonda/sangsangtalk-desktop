# 상상톡 디자인 — 메인 화면 v1

시안: `main-screen.html` (1280×800 기준). 미리보기: `.claude/launch.json`의 `design` 구성
(`python -m http.server 43180 --directory design`) → http://localhost:43180/main-screen.html

## 레이아웃 (3단)
| 영역 | 폭 | 내용 |
|---|---|---|
| 레일 | 76px | 엠블럼, 대화·직원·쪽지·즐겨찾기 / 알림·설정·내 프로필(상태 점) |
| 대화 목록 | 340px | 브랜드(상상톡 글자), 새 대화, 검색, 필터 칩(전체/안읽음/그룹/1:1), 고정됨·최근 대화, 마스코트 인사 카드 |
| 대화창 | 나머지 | 헤더(방 이름·인원·접속 수·액션), 공지 바, 메시지 로그, 입력창 |

≤900px: 레일(64px) + 목록만 보이고 대화창은 목록 ↔ 대화 전환형(현재 `thread-back` 동작과 같음).

## 색 토큰 (`:root` 참고)
- 브랜드: `--navy-700 #0b4a8f`(레일), `--teal-600 #149488`(주 버튼·내 말풍선·선택), `--sun-500 #f08a24`(안읽음 배지·미확인 수)
- 마스코트: `--lime-500 #8fc23a`(온라인), `--lime-100`(마스코트 배경), `--grape-700`, `--sky-500`(포커스 링)
- 중립: `--ink #1b2430` / `--ink-2` / `--ink-3`, `--line #e3e9ee`, `--chat-bg #f1f6f7`
- 상태 점: 온라인 lime, 자리비움 `#f3b63f`, 오프라인 `#b8c1ca`

## 규칙
- 글꼴: Pretendard → Malgun Gothic. 본문 14px, 방 이름 14.5px/700, 메타 11.5–12.5px.
- 반경: 8/12/18px. 아바타는 둥근 사각(46px, r16 / 소 36px, r13). 사람은 이름 2글자 + 색, 그룹은 아이콘.
- 메시지: 상대 = 흰 말풍선(좌상단 모서리 4px), 나 = teal(우상단 4px). 같은 사람 연속 메시지는 아바타·이름 생략(`.cont`).
  시간 옆 주황 숫자 = 아직 안 읽은 사람 수.
- 프로필 사진이 없는 사용자(나 포함) 기본 아바타 = 거북이 정면(`assets/turtle-front.png`).
- 마스코트 PNG는 흰 배경을 투명 처리했지만 눈 흰자도 일부 투명하므로 **밝은 배경 위에만** 쓴다(`mix-blend-mode:multiply`).
- **엠블럼은 음성군 공식 로고를 쓴다.** 원본 `assets/eumseong-emblem-original.jpg`(1200px, 흰 배경), 화면용 `assets/emblem.png`(256px, 원형 투명).
  로고 사용 규칙: 항상 원형 그대로 쓰고 늘이기·잘라내기·색 바꾸기·회전·글자 겹치기는 하지 않는다. 화면 최소 크기는 24px(레일은 44px).
  남색 배경(레일 등) 위에서는 경계가 묻히지 않게 바깥에 흰 링 2px를 두른다(`box-shadow:0 0 0 2px #fff`).
  더 큰 크기나 인쇄물이 필요하면 원본 JPG에서 다시 잘라 쓴다.
- ∞(뫼비우스 띠) 마크는 **삭제**했다(사용자 결정 11/16). 브랜드는 "상상톡" 글자만 쓴다.

## 에셋
`assets/emblem.png`(음성군 공식 로고, 원형), `assets/eumseong-emblem-original.jpg`(로고 원본), `assets/turtle-front.png`(기본 아바타), `turtle-thumbs.png`(인사 카드), `turtle-jump.png`, `turtle-side.png`(빈 화면·완료 안내 등 예비).

## 1. 상태 점·글자 (D)
- 점 12px, 흰 테두리 2px, 아바타 오른쪽 아래(-2px 바깥). 내 프로필(레일)은 14px, 테두리는 레일 남색 `--navy-900` 2.5px.
- **색만으로 구분하지 않는다**: 점 옆이나 가까이에 상태 글자(12px/600, `-ink` 색, 오프라인만 500)를 함께 쓴다.
  - 1:1 목록: 이름 바로 뒤에 상태 글자. 행 전체 `title="김도윤 · 사용 중"`.
  - 직원 고르기(그룹 만들기·초대): 행 오른쪽 끝에 상태 글자.
  - 1:1 대화창 머리글: 이름 아래 줄에 점 + 상태 글자(v1의 `.live` 자리).
  - 레일 내 프로필: 사진 아래 10.5px 흰색(75%) 글자 "사용 중", 사진 `title="박지민 · 사용 중"`.
- 문구는 정확히 `사용 중` · `자리비움` · `오프라인`.
- 그룹 대화방에는 상태 점을 달지 않는다.

## 2. 새 대화 메뉴 (B)
- 목록 머리글의 **"＋ 새 대화 ⌄" 알약 버튼**(아래 규격) → 아래로 팝오버(260px, r14, `--shadow-3`, 버튼 오른쪽 끝에 맞춤). `aria-haspopup="menu"`, 열리면 `aria-expanded="true"`.
- 알약 버튼 규격(`.new-btn`):

  | 항목 | 값 |
  |---|---|
  | 크기 | 높이 34px, radius 17px, 안쪽 여백 좌 8px · 우 12px, 요소 간격 6px |
  | 바탕 / 그림자 | `--teal-600`, `0 2px 8px rgba(20,148,136,.28)` |
  | 글자 | "새 대화", 흰색 13px/700, 줄바꿈 없음 |
  | + 아이콘 | 18px 원(흰색 18% `rgba(255,255,255,.18)`) 안에 흰 + 12px(선 2.4) |
  | 셰브론 | 12px 아래 화살표(흰 선 2), 글자 오른쪽 |
  | 호버 · 메뉴 열림 | 바탕 `--teal-700`. 열림(`aria-expanded="true"`)이면 셰브론 180° 회전(0.15s, 동작 줄이기 설정이면 즉시) |
  | 접근성 | 보이는 글자가 이름이므로 `aria-label` 없음. +·셰브론은 `aria-hidden` |
- 항목 2개: **1:1 대화**(teal-50 아이콘 상자, "직원 한 명과 바로 대화") / **그룹 대화**(navy-100 아이콘 상자, "여러 명을 골라 대화방 만들기"). 아이콘 상자 36px r11.
- 바깥 클릭·Esc로 닫는다. v1의 필터 아이콘 버튼은 v2에서 뺐다.

## 3. 그룹 만들기 대화상자 (B)
- 520px, r20, 어두운 막 `rgba(10,28,48,.42)`. 머리글 제목 18px/800 + 설명 "함께 대화할 직원을 고르세요. 나는 자동으로 들어갑니다."
- 순서: 대화방 이름 입력(42px) → 선택 칩 → 검색 → 직원 목록 → 하단 버튼.
- 이름 입력의 placeholder는 **비워 뒀을 때 실제로 붙을 이름**(참여자 3명 + "외 N명", 계약서 B). 나는 이름에도 N에도 세지 않는다(PM 결정 11/16). 도움말 "비워 두면 참여자 이름으로 정해집니다."
- 선택 칩: 30px, teal-50 바탕, 22px 아바타 + 이름 + × (aria-label "김도윤 빼기"). 앞에 "선택 N명".
- 직원 목록: 최대 높이 270px 스크롤, 부서 머리글(sticky, 부서명 + 인원). 행 = 체크박스 22px(r7, 선택 시 teal) · 아바타 36px · 이름/직위 · 상태 글자. 나는 체크·비활성 + "나" 표시.
- 하단: `취소`(ghost) · `만들기 (N명)`(primary, N은 나 포함). 0명 선택이면 비활성.
- **초대** 대화상자는 같은 틀: 제목 "참여자 초대", 이름 입력 없음, 이미 참여한 사람은 체크·비활성 + "참여 중", 버튼 `초대 (N명)`.
- **이름 바꾸기**는 같은 틀의 작은 대화상자(400px): 이름 입력 하나 + `취소`/`저장`.

## 4. 목록 "그룹" 구역·그룹 머리글 (B)
- 목록 순서: 고정됨(전체 채널) → **그룹 N** → 1:1 대화.
- 그룹 행: navy-100 사람들 아이콘 아바타, 이름 뒤에 인원 수(12px/600 ink-3), 미리보기는 "보낸 사람: 내용", 내가 보냈으면 "나: …".
- 그룹 대화창 머리글: 이름 옆 인원 칩(22px, navy-100/navy-700, 사람 아이콘 + 숫자, `title="참여자 6명"`), 아래 줄에 참여자 이름 나열(나는 끝에 "나").
- 더보기(⋯) → 메뉴 200px: 이름 바꾸기 · 참여자 초대 · 구분선 · **대화방 나가기**(danger 글자, 호버 danger-50).
- 나가기 확인(alertdialog, 400px, 가운데 정렬): 거돌이(옆모습) 76px, 제목 "‘방 이름’에서 나갈까요?", 본문 3줄(새 메시지 안 받음 / 다시 들어오려면 초대 / 기록은 지워지지 않음), 버튼 `취소` · `나가기`(danger) 같은 폭.
- 시스템 줄(가운데 12px ink-3): "김도윤 님이 강예린 님을 초대했습니다." 같은 초대·나가기·이름 변경 알림.
  - **보류(다음 단계)**: 서버 데이터 필요. 1단계 구현에서는 표시하지 않는다.

## 5. 파일 첨부·업로드 진행 (C)
- 입력창 도구줄 왼쪽에 **글자 붙은** 첨부 버튼 `📎 파일`(34px, 13px/600). 오른쪽 안내 "끌어다 놓거나 붙여넣어도 됩니다 · Enter 전송".
- 올리는 파일은 입력창 **안쪽 위**에 한 줄씩(`.uploads`, 행 r12, `--bg` 바탕):
  - 올리는 중: 형식 배지 28px · 이름 · "8.6MB 중 5.2MB · 60%" · 진행 막대(4px, teal) · × 취소.
  - 준비됨: "✓ 준비됨"(teal-700) · × 빼기.
  - 실패: danger-50 바탕, 이유 한 줄(12px danger-600), `다시 시도`(전송 실패일 때만) · × 빼기.
    - 크기 초과(보내기 전 검사, 413): "파일이 너무 큽니다. 파일당 100MB까지 보낼 수 있어요." — 다시 시도 없음.
    - 막는 형식(415): "보낼 수 없는 형식입니다(.exe)." — 다시 시도 없음.
    - 연결 오류: "올리지 못했습니다. 연결을 확인하고 다시 시도하세요." — 다시 시도 있음.
- 하나라도 올리는 중이면 전송 버튼 비활성 + `title="올리는 중인 파일이 끝나면 보낼 수 있어요"`. 준비된 파일이 있으면 글이 없어도 보낼 수 있다.
- **끌어다 놓기**: 대화창 전체를 덮는 막(rgba chat-bg .86) 안에 점선 테두리(2.5px teal-500, r22) 상자, 거돌이(점프) 120px, "여기에 놓으면 파일을 올립니다"(19px/800 teal-700), 방 이름 줄, 제한 안내 줄. 목록·레일은 덮지 않는다.

## 6. 파일 카드·이미지 썸네일 (C)
- 파일 카드: 320px(최대 100%), 흰 바탕, r12, 1px `--line-2` 테두리. 내 메시지도 **흰 카드**(teal 말풍선 안에 넣지 않는다) + 테두리 teal-100.
  - 형식 배지 38×46, 오른쪽 위 접힌 모서리, 아래쪽에 확장자 대문자(10.5px/800).
  - 이름 13.5px/600 한 줄 말줄임, 아래 "크기 · 종류"(12px ink-3). 크기를 모르면(`size:null`) 종류만 표시("압축"). 이미지 캡션도 크기를 모르면 이름만.
  - 크기 표기: 1KB 미만도 "1KB"로 올려 쓰고, 이후 KB·MB(소수 첫째 자리, 10 이상은 정수). B 단위는 쓰지 않는다. 업로드 행도 같은 규칙.
  - 오른쪽 내려받기 버튼(teal-700 아이콘, aria-label "내려받기").
- 형식 → 색·종류 글자: PDF 빨강 "PDF" · HWP/HWPX 하늘 "한글" · XLSX/XLS/CSV 초록 "엑셀" · DOCX/DOC 남청 "워드" · ZIP/7Z 보라 "압축" · 그 밖 회색 "기타"(배지에는 실제 확장자, 4자까지).

## C3 워터마크
- 대화 기록 영역 **뒤**에 "이름 · 로그인 ID · 날짜"(예: `박지민 · 2026012 · 2026-11-17`)를 13px/600, `rgba(27,36,48,.07)`, −24° 기울여 가로 260 · 세로 140px 간격으로 엇갈려 반복. 말풍선·카드는 불투명이라 글을 가리지 않는다.
- 입력창·목록·머리글에는 넣지 않는다. 스크롤해도 화면에 고정(대화 영역 크기의 고정 층). `pointer-events:none`, `aria-hidden`, 선택·복사되지 않게.
- `WATERMARK=0`이면 그리지 않는다(`#nowm`). 로그인 ID는 앞 7자까지.

## C4 잠금 화면
- 창 전체를 남색 그라데이션으로 **완전히 덮는다**(흐리게가 아니라 가림). 가운데 380px 카드: 엠블럼 52px → "상상톡이 잠겨 있습니다" → "30분 동안 사용하지 않아 화면을 잠갔습니다." → 내 이름·직위·부서 → 비밀번호 → **잠금 해제** → "로그아웃하고 다른 계정으로".
- 분 숫자는 `AUTO_LOCK_MINUTES` 값. 열리면 비밀번호 칸에 포커스, Esc로 닫히지 않는다.
- 틀리면(`#lockerr`) 칸 빨간 테두리 + "비밀번호가 맞지 않습니다. N번 더 틀리면 로그아웃됩니다."(`role="alert"`). 5번째에 로그인 화면으로.
- 잠긴 동안 새 메시지 알림은 보내는 사람 이름만, 본문은 숨긴다(데스크톱 알림 포함).
