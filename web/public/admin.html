알림

알림 미리 보기 숨김 강제켜면 모든 직원의 Windows 알림에 "상상톡 · 새 메시지가 왔습니다"만 보입니다. 직원은 설정에서 바꿀 수 없고, 중요 메시지도 이 규칙을 따릅니다.
지금 모든 직원의 알림 미리 보기가 "숨김"으로 고정되어 있습니다. 직원 설정 화면에는 "기관 정책으로 고정됨"이 보입니다.

업로드 차단 파일 형식

이 형식의 파일은 보낼 수 없습니다. 서버가 다시 검사하며, 막힌 파일을 보내면 "기관 정책으로 막힌 파일 형식입니다."가 표시됩니다.

업로드 최대 크기 읽기 전용

파일 하나 기준서버 설정(MAX_UPLOAD_MB)에서 바꿉니다. 바꾸려면 시스템 담당자에게 요청하세요.
